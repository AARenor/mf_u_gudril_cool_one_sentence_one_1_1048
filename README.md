# one-sentence journey

This is a small program that writes one short text for make.fun's bounty `u-gudril-cool-one-sentence-one-journey-410686ca` — a complete story about a journey told in exactly one sentence — and the same sentence is the whole entry.

[![reward](https://make.fun/badge/u-gudril-cool-one-sentence-one-journey-410686ca/AARenor/mf_u_gudril_cool_one_sentence_one_1_1048/reward.svg)](https://make.fun/bounty/u-gudril-cool-one-sentence-one-journey-410686ca)

```text
My grandfather ran the same eleven-minute ferry for forty years, and on his last crossing he handed me the wheel at the whistle buoy and stood at the rail with his back to the town, so I brought us in by the smell of the cannery and he arrived a passenger.
```

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

It writes `entry.txt` (UTF-8, no trailing newline) and prints the character count to stderr.
